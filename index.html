乾手工強度對照表 Dry Hand Work Intensity Reference

建立 HandSand／PP Spray／PP Rub／Laser 強度對照表與資料庫，讓工人容易理解工序級別，將工序標準化，以達到更好的品質。

An intensity reference and database for HandSand, PP Spray, PP Rub and Laser, so workers can easily understand process levels. It standardises the processes for better quality.

執行要求

  • 製作不同工藝版本，以及各工序配搭的組合版本。
  • Laser 強度版本需參考 YDVL - Zhi 的資料，請聯絡他取得。
  • 全部使用 AEO 客戶布料製作。
  • 所有版本都要記錄副本。
  • 所有洗水都在 250 lbs 機中進行。

Requirements

  • Make the different process versions and the combined versions of each process.
  • Laser intensity versions need reference data from YDVL - Zhi. Please contact him to get it.
  • All versions are made on AEO customer fabrics.
  • A duplicate must be recorded for every version.
  • All washing is done in a 250 lbs machine.

打板標準

  • 砂紙規格、擦拭次數、力度必須全部明細標註。
  • 首板出問題會連帶影響後續生產，打板操作必須標準化。

Sampling standard

  • Sandpaper spec, number of rubs and pressure must all be marked in detail.
  • A problem in the first sample affects later production, so sampling must be standardised.

呈現方式：車間實體看板

  • 全部測試實樣與對應參數製成實體看板，張貼於生產車間牆面，不裝訂成紙本手冊，避免無人翻閱。
  • 看板兼作實操教材，本地新員工可對照學習，不必完全依賴師傅口口相傳。

Presentation: physical boards on the production floor

  • All test samples and their parameters are made into physical boards and posted on the production floor wall, not bound into a paper manual, so they do not go unread.
  • The boards also work as hands-on training: new local staff can learn by comparing, without relying only on senior workers' word of mouth.
